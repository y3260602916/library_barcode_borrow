# 校园图书条码借阅系统 - 数据库设计
## 一、数据库基本信息
数据库名称：library_db
字符集：utf8mb4
数据库版本：MySQL 8.0

## 二、数据表说明
1. sys_user 用户表：存储师生、管理员账号信息
2. book_info 图书表：存储图书基础信息与条码编号
3. borrow_record 借阅记录表：记录图书借阅、归还、逾期数据
4. scan_record 条码识别记录表：记录AI图片识别日志、图片路径与结果

## 三、表关系说明
1. 用户表 与 借阅记录表：一对多，一个用户可产生多条借阅记录
2. 图书表 与 借阅记录表：一对多，一本图书可被多人借阅
3. 识别记录表：独立日志表，记录所有AI识别行为

## 四、设计规范
1. 图片文件保存在本地目录，数据库仅存储文件路径，降低数据库压力
2. 所有主键自增，关键字段设置非空、唯一约束
3. 借阅表设置外键关联用户与图书，保证数据完整性
